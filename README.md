# Club Mode
Club Mode is a utility for Mac and Windows which makes Rekordbox a better practice tool for DJs preparing to use club gear. Features include split waveforms, BPM precision adjustment and fully functional CDJ-style phase meters. [See it in action!](https://www.instagram.com/p/DcL49ovoXiX/)

Club Mode is free, but please consider supporting its development [here.](https://ko-fi.com/thosearcheryguys)

## Mac Version Info

(Windows info further below 👇)

**System Requirements**

The current Mac beta (v0.12.20) supports:
* Apple Silicon Macs (M1 or newer)
* macOS 14 Sonoma or later
* rekordbox 7.2.16–7.2.19

Club Mode may not work correctly with older versions of rekordbox.

**Installation**
1. Download the DMG from the latest release
2. Open the DMG and drag Club Mode into your Applications folder
3. Open Club Mode from Applications
4. Follow the permissions guide
5. Open rekordbox in Performance mode and select 2 Deck Horizontal

**Troubleshooting**

If an overlay does not appear:
* Confirm that Club Mode is enabled
* Confirm that rekordbox is in 2 Deck Horizontal mode
* Check both permissions under Club Mode → Settings
* Quit and reopen Club Mode after granting Screen Recording permission
* Make sure you are using a supported rekordbox version (7.2.16 or newer)
* [Submit an issue](https://github.com/thosearcheryguys/club-mode/issues) for persistent problems, including the output from Settings → Copy diagnostics



## Windows Version Info

**System Requirements**

The current Windows beta (v0.1.41) has been verified with:
- Windows 10 22H2 on Intel/AMD 64-bit PCs
- .NET Framework 4.8.1
- rekordbox 7.2.18–7.2.19
- Windows display scaling of 100%, 125%, 150% or 175%

**Installation**

1. Download the Windows ZIP from the releases page
2. Extract the entire ZIP into a writable folder, such as Documents
3. Keep all extracted files and folders together
4. Double-click Start Club Mode.cmd
5. Open rekordbox in Performance mode and select 2 Deck Horizontal
6. Enable Club Mode, choose your features, then return to rekordbox

**Troubleshooting**

If an overlay does not appear:
- Confirm that Club Mode is enabled and rekordbox is the active window
- Confirm that rekordbox is in 2 Deck Horizontal mode
- Open Club Mode → Settings and select Check again
- Make sure you are using a tested rekordbox version
- On larger displays, try narrowing the rekordbox window
- Restart both applications after changing Windows display scaling
- [Submit an issue](https://github.com/thosearcheryguys/club-mode/issues) for persistent problems, including the output from Settings → Copy diagnostics
