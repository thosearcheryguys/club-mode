# Club Mode
Club Mode is a Mac app which makes Rekordbox a better practice tool for DJs preparing to use club gear. Features include split waveforms, BPM precision adjustment and fully functional CDJ-style phase meters.

Club Mode is free, but please consider supporting its development [here.](Ko-fi.com/thosearcheryguys)

---
**System Requirements**
The current beta supports:
* Apple Silicon Macs (M1 or newer)
* macOS 14 Sonoma or later
* rekordbox 7.2.16–7.2.18 

Club Mode may not work correctly with older versions of rekordbox.

**Installation**
1. Download the ZIP from the latest release
2. Open the ZIP and drag Club Mode.app into your Applications folder
3. Open Club Mode
4. Follow the permissions guide
5. Open rekordbox in Performance mode and select 2 Deck Horizontal

**Troubleshooting**

If an overlay does not appear:
* Confirm that Club Mode is enabled
* Confirm that rekordbox is in 2 Deck Horizontal mode
* Check both permissions under Club Mode → Settings
* Quit and reopen Club Mode after granting Screen Recording permission
* Make sure you are using a supported rekordbox version (7.2.16 or newer)
* [Submit an issue]([url](https://github.com/thosearcheryguys/club-mode/issues)) for persistent problems
